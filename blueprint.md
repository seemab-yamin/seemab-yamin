# **App Name**: Seemab Yamin Portfolio

## Core Features:

- Header/Hero Section: Displays Seemab's name, title (Python Engineer/ LLM enthusiast), and a 'Download Resume' button, linking to the resume.
- About Me Section: Showcases a professional summary highlighting experience with Python, ETL pipelines, AWS, and AI, plus a list of key technical skills.
- Projects Section: Displays 4-6 projects in a grid layout, each with a title, description, and links to the live demo and GitHub repository.
- User Testimonials Section: Implements a rotating carousel to display 3 client/peer testimonials.
- Footer Section: Presents simple contact links: email, LinkedIn (www.linkedin.com/in/seemab-yamin), and GitHub (https://github.com/seemab-yamin/).

## Style Guidelines:

- Primary color: Teal (#008080) to give a professional and trustworthy feel.
- Background color: Dark gray (#222222) to provide a modern dark mode aesthetic. Should be lighter than true black.
- Accent color: Light teal (#70dbdb) for interactive elements, links, and highlights to create emphasis.
- Body text: 'Inter' sans-serif font to be used for the majority of the portfolio; readable, clean and modern.
- Headline font: 'Space Grotesk' sans-serif font for the header, section titles, and project titles.
- Use minimalist, line-based icons for skills and contact links to maintain a clean aesthetic.
- Emphasize a clean, single-page layout, making use of subtle section dividers to clearly define each area. All the sections listed in the prompt should be on a single page, displayed in the requested order.
- Add subtle fade-in effects when scrolling to different sections to enhance user experience.
