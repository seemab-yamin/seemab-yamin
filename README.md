# Seemab Yamin Portfolio Website

A modern, responsive portfolio website for Seemab Yamin, a Python Engineer and LLM Enthusiast.

## Features

- **Responsive Design**: Fully responsive layout that works on all devices
- **Modern UI**: Clean, professional design with dark theme
- **Interactive Elements**: 
  - Smooth scroll animations
  - Fade-in effects on scroll
  - Interactive testimonials carousel
  - Hover effects on projects and skills
  - Ripple effects on buttons
- **Sections**:
  - Hero/Header with name and title
  - About Me with professional summary and skills
  - Projects showcase with 6 featured projects
  - Rotating testimonials carousel
  - Contact information with social links

## Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Modern styling with Flexbox and Grid
- **JavaScript**: Interactive functionality and animations
- **Google Fonts**: Inter and Space Grotesk font families
- **Font Awesome**: Icons for social links and UI elements

## Design Guidelines

- **Primary Color**: Teal (#008080) - Professional and trustworthy
- **Background**: Dark gray (#222222) - Modern dark mode aesthetic
- **Accent Color**: Light teal (#70dbdb) - Interactive elements and highlights
- **Typography**: 
  - Body text: 'Inter' sans-serif
  - Headlines: 'Space Grotesk' sans-serif
- **Layout**: Single-page design with smooth scrolling navigation

## File Structure

```
├── index.html          # Main HTML file
├── styles.css          # CSS styling
├── script.js           # JavaScript functionality
├── Python Resume - Seemab Y.pdf          # Resume download file
├── blueprint.md        # Design specification
└── README.md           # Project documentation
```

## Setup Instructions

1. Clone or download the project files
2. Open `index.html` in a web browser
3. No build process required - pure HTML/CSS/JS

## Customization

To customize the portfolio:

1. **Personal Information**: Update the content in `index.html`
2. **Styling**: Modify colors and design in `styles.css`
3. **Projects**: Replace project information in the projects section
4. **Resume**: Replace `resume.txt` with your own resume file
5. **Contact Links**: Update social media and contact links
